How it works

Extract

pypdf pulls text page by page, so page numbers survive.

Chunk

1000-char windows, 200 overlap, never crossing a page.

Embed

bge-small runs locally on CPU through ONNX.

Retrieve

Cosine search over the course's chunks, top 5.

Ground

Numbered sources go into a strict prompt.

Answer

The LLM replies with [n] citations you can check.
